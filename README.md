# Customer Segmentation using RFM Analysis

## 📌 Project Overview

This project focuses on customer segmentation using **RFM Analysis (Recency, Frequency, and Monetary Value)**. The project was developed using **Microsoft Power BI** to analyze customer purchasing behavior and identify different customer segments.

RFM analysis helps businesses understand customer behavior and create targeted marketing strategies.

## 🎯 Objectives

- Clean and prepare customer transaction data
- Calculate Recency, Frequency, and Monetary metrics
- Segment customers based on their purchasing behavior
- Analyze customer demographics
- Identify valuable, loyal, new, and at-risk customers
- Create an interactive Power BI dashboard
- Provide marketing recommendations for different customer segments

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Excel / CSV
- Data Visualization
- RFM Analysis

## 📈 RFM Analysis

### Recency

Measures how recently a customer made a purchase.

### Frequency

Measures how frequently a customer makes purchases.

### Monetary

Measures how much money a customer spends.

## 💡 Key Insights

- Champions contribute significantly to overall sales.
- Loyal customers show strong purchasing behavior.
- At-risk customers can be targeted with retention campaigns.
- New customers can be encouraged to make repeat purchases.
- High-value customers can be targeted with personalized offers.
- RFM segmentation helps businesses create customer-specific marketing strategies.
